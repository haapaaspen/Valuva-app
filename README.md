# Valuva - Motion Graphics App

Valuva is an intuitive animation application that makes motion graphics accessible through innovative forcefield animation tools.

## About

Valuva allows users to create complex animations using a forcefield-based approach, where elements are attached to paths and influenced by forcefield dynamics, resulting in smooth and natural motion.

## Features

- **Forcefield Animation**: Create natural-looking animations using path-based forcefields
- **Multiple Layers**: Organize your project with a powerful layer system
- **Timeline Editor**: Precise control over your animations with a full-featured timeline
- **Cross-Platform**: Works on both mobile and desktop platforms
- **Intuitive Interface**: Dark-themed UI designed for creative work

## Getting Started

### Prerequisites

- Flutter SDK (3.0.0 or higher)
- Dart SDK (3.0.0 or higher)

### Installation

1. Clone this repository
   ```
   git clone https://github.com/yourusername/valuva.git
   ```

2. Navigate to the project directory
   ```
   cd valuva
   ```

3. Install dependencies
   ```
   flutter pub get
   ```

4. Run the app
   ```
   flutter run
   ```

## Development Status

This project is currently in prototype phase. The main focus is on implementing the forcefield animation feature and providing an intuitive user interface.
