# Product Requirements Document (PRD)

## App Overview
- **Name:** Valuva
- **Tagline:** "Motion graphics is for everyone"
- **Description:** An intuitive animation app for iOS and web (with future Android support) that makes motion graphics accessible through innovative forcefield animation tools.
- **Target Launch:** Prototype ASAP, MVP by September


## Target Audience

### Personal Users
- Non-technical artistic people who use tools like Procreate but find animation intimidating
- Technical graphic designers seeking a playful, experimental approach to animation

### Professional Users
- Content creators, event organizers, and video editors
- Professionals looking to enhance their content with animations


## Key Features

### 1. Core Design Environment
- Canvas-based workspace
- Elements panel with tools
- Layers panel for organization
- Context-sensitive design panel

### 2. Standard Design Tools
- Basic shape creation
- Text elements
- Image import and manipulation
- Layer management

### 3. Forcefield Animation Tool
- Path-based animation system where forcefields are drawn like strokes
- Elements on the same layer can be dragged onto the forcefield and become its "children"
- Elements automatically snap to the forcefield path 
- Elements remain stationary until animations are played
- Direction toggle (can reverse the direction drawn)
- Speed dial for controlling animation rate
- Visual representation as a transparent, animated "river/wind" to indicate flow direction
- Custom animation recording capabilities through various input methods

### 4. Animation Controls
- Global timeline slider with playback and record button to visualize the entire animation
- Individual forcefield controls in the design panel:
  - Direction toggle
  - Speed dial
  - Local slider + play/pause + record buttons
  - Animation selection list (defaults like "linear" plus saved recordings)
- Multiple input methods:
  - Mobile: Touch sliders, device pitch/yaw sensors, virtual joysticks by combining sliders
  - Desktop: Keyboard bindings for animation direction control
- Ability to "pop" sliders into floating windows for visibility even when elements aren't selected

## User Experience
- Dark, rounded UI consistent with professional video editors
- Mobile: Top bar interface with expandable panels
- Desktop: Figma-like panel arrangement

## Development Timeline
- Proof of concept: ASAP for investor pitching and team recruitment
- MVP: September (following completion of school and vacation)

## Success Metrics
- User engagement with the forcefield feature (time spent using this specific tool)
- Time to create first animation (under 5 minutes indicates good UX)
- Percentage of users who successfully create and save a forcefield animation
- User retention and repeat usage (weekly active users)
- User satisfaction with the intuitiveness of the animation tools
